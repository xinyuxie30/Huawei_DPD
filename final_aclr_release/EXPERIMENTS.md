# ACLR 优化实验全记录(2026-07-13 ~ 07-14)

面向华为 E3 轻量级 AI DPD 的四个发布模型(2284 / 998 / 786 / 796 实乘法器),
在 NMSE 约束(≤ −40 / −37 / −35 / −35 dB)下优化 ACLR。本文件按时间线记录**全部尝试**,
包括负结果——负结果决定了路线取舍,与正结果同等重要。

数据与纪律:`data/DPD_data.mat`(fs=491.52 MHz),前 80% 训练 / 后 20% 验证,
所有指标在**验证段**评估(区别于参考队的全数据同数据评估);Welch nperseg=4096。

---

## 第一阶段:三指标口径(我方原口径)

口径:full(邻带 ±(120,180) 误差 PSD dB 均值 − 主带 (20,80) 目标 dB 均值)、
point(最低 bin 差)、narrow(固定 5 MHz 窄带),三者取最差。

| 尝试 | 结果 | 结论 |
|---|---|---|
| 基线评估 | 2284 三指标最差 −42.98,轻量组 −38~−40 | 全员距 −45 有 2~7 dB |
| FIR-only 梯度微调 | 30 epoch 全员持平或变差 | 输出 FIR 已被闭式 LS 拟合到位,梯度只造成漂移 |
| 闭式频域加权岭 LS FIR 扫参(Toeplitz 快速解,162 候选/模型) | 全员 ≤0.1 dB | **线性 FIR 无剩余杠杆**(邻带误差由非线性底座决定) |
| v1 可微惩罚(单帧周期图 log 均值+min 项) | NMSE 与 ACLR 同时变差 | log 域逐 bin 梯度被深谷 bin 主导,与 Welch 口径失配 |
| v2 SpectralPenalty(批内平均功率谱再取 dB + 帧边裁剪 + 常量参考) | 三指标同步单调改善 | 可微 ACLR 手段的正确构造方式 |
| v2 推压 + 前沿测绘 | 2284 饱和于 −43.06;放宽 NMSE 至 −38.6 只换 0.24 dB | 兑换率 ~0.2 dB/dB 且快速饱和 |
| 数据集参考 error 摸底 | 全带均值口径仅 −43.5~−43.7 | 该口径下 −45 连参考残差都不达标 |

**阶段结论:旧口径的绑死指标(全带 dB 均值)-45 不可达。**

## 第二阶段:参考队(APNKAN 报告)口径复现与机制分析

对照 UESTC 非线性小队报告(`other/refdesign_main_pdf.txt`):

1. **口径锁定**:他们 ACLR = 双边邻带 (100,180) **积分功率**合并 ÷ 主带 ±100 积分功率。
   数据集 error 按此复现 −44.75/−44.83,与其图 8 标注 −44.59 差 0.16 dB。
2. **归一化不变性**:rms 与 max 归一化下 NMSE/ACLR 逐位相同(比值指标);
   归一化只影响 MSE<1e-4 阈值解读(max 口径 ⇔ NMSE ≈ −24 dB,单位功率 ⇔ −40 dB,差 16 dB)。
3. **他们 −51.75 的三层归因**:规则解读(带内预算 10+ dB 可挥霍)、协议(1:0:0 全数据训练同数据评估,
   报告自认无独立验证)、架构(相位归一化 + 样条 LUT 的邻带表征效率,兑换率 0.86 dB/dB 不饱和)。
4. 我方 2284 按其口径 = −44.09(基线),距 −45 仅 0.91 dB。

## 第三阶段:子带渐进微调(照搬机制)→ 饱和

他们的机制:L = (1−r)·mean|e|² + r·mean|HPF(e)|²,r 渐进至 0.9999(HPF=257 阶 98 MHz 高通,
时域滤误差,与积分口径 Parseval 对齐,无 PSD 估计器失配)。加 NMSE guard(拉格朗日式约束)。

- 探测轮(r≤0.99)全员饱和;第二轮上强度(r=0.9999、加密步数、400 ep):
  2284 +0.10(guard 锁死 NMSE)、998 +0.55(烧 2.4 dB NMSE)、786/796 +0.6~0.8(烧 4 dB)。
- **无 in-sample 差距**(训练段≈验证段)→ 撞容量墙不是泛化墙,照搬全数据协议也无用。
- **兑换率是架构属性**:EA-TCN 家族 0.2~0.25 dB/dB 且 <1 dB 即饱和。

## 第四阶段:架构迁移 —— 相位归一化样条 LUT 支路(关键突破)

`steps/aclr_phase_spline_experiment.py`:在 EA-TCN 输出 FIR 之前加校正支路
`corr = conj(r)·Σᵢ splineᵢ(featᵢ)`,r=conj(x)/|x|,feat=[|x|, Re/Im(x(n±m)·r)],
一阶样条查表(G=24,零初始化=起点无损)。**MAC 严格支付**:按 APNKAN 口径
2·N_in+N_edge + 旋回 4 + 邻居旋转全计入,由 FIR 减抽头精确抵偿(±1→32 MAC/−8 抽头,
±2→56/−14)。训练:先只训表、再底座联合,全程 HPF 子带损失 + guard + 周期闭式 FIR 重拟合。

**同 MAC、NMSE 不损(≤0.13 dB)下:2284 +0.36、998 +0.86、786 +1.04、796 +1.39 dB ACLR。**
对比子带微调烧 2.4~4 dB NMSE 才换 0.5~0.8——这是唯一验证有效的"免费 ACLR"手段。

## 第五阶段:最小点口径 + min-point 机器移植

最小点口径(主 (20,80) 最低 bin 为参考)下 2284 spline 顺带过线(−45.30 ≤ −45 @ NMSE −40.11)。
把 `aclr_min_point_optimization.py` 的整套机制(退火 soft-min 替代、NMSE 门控梯度手术、
信任域、硬指标验收+回滚、权重外推线搜索)移植到 spline wrapper(`aclr_phase_spline_minpoint.py`):

- 四模型 3/4 刷新(2284 −45.35 / 998 −43.02 / 796 −41.14;786 输给原线 −41.52)。
- **负结果:闭式 FIR 凹槽扫描无效**(Welch 最低点贴在底座-目标**非相干地板**上,
  FIR 只能消相干分量)——min-point 深度只能靠动底座权重。
- 负结果:预算燃烧模式(NMSE 有余量时去掉下降项纯谱推进)无效——卡的是相干地板不是预算。
- 意外馈赠:**wrap+截断+LS 重拟合会大幅搬动 Welch 最低点位置**(786 从 −41.52 变 −41.74),
  FIR 变体成为廉价的最低点"重掷骰子"手段 → 衍生出 FIR point 扫参(`aclr_wrapper_fir_pointsweep.py`,
  含随机分段权重画像)。

## 第六阶段:凸活跃 bin 表优化 + lag 拓扑搜索

- `aclr_active_bin_table_optimization.py`:缓存底座输出,对决定最低点的**两个活跃 bin**
  做样条表凸(L-BFGS)拟合 + α 线搜索 + 硬指标验收,多轮交替;重压配方(5 轮×4 候选 bin×宽谱权重)。
- `aclr_lag_topology_search.py`:同 MAC 下搜索样条支路的 lag 集合(表行语义移植),
  796 最优拓扑 (−2,−1,0,2,3)、786 (−1,0,3)。
- 该线把数字推到:2284 −45.98 / 998 −43.85 / 786 −42.36(lm2 拓扑) / 796 −41.72。

## 第七阶段:从零渐进轨迹(参考队完整路线复刻)→ 判负

`--init scratch`(LS 一阶增益 + 残差零初始化)+ r 渐进 0→0.9999 完整训练(600~800 ep):

- 998:NMSE 渐近 −36.63 **不达标**(原版靠蒸馏才到 −37.37),且同 NMSE 下 point 差微调线 ~2 dB;
- 786/796:达标但 point 分别 −40.22/−40.39,差微调线 1~1.5 dB。

**结论:我方 TCN 架构从随机初始化训不出微调血统的质量;参考队的从零优势是其
逐样本 KAN 架构特有的(500 ep 即到 NMSE −40)。微调发布模型是我方的正确范式。**

## 第八阶段:新预算(2284≤2399、786≤800、998/796 锁定)

- `aclr_spline_transplant.py`:底座复制 + 表行按 lag 语义映射 + FIR 零填充(**恒等移植**,
  起点即冠军水平,新增容量停在零)。
- 2284 +115 MAC → **±4 九抽头样条支路 + 满 43 抽头 FIR**(2388 MAC):
  凸雕刻线到 **−46.16**,平滑线积分推到 −44.74。
- **786 +14 MAC 全部无效**(第 4 个 lag 三种拓扑、FIR 33→35 均零增益)——瓶颈是相干性不是容量。
- 998/796 锁定预算下重压配方再挤 +0.15 / +0.23。

## 第九阶段:谱形优先标准

评价标准修正:**残差 PSD 必须贴近数据集参考 error 的形状**,人工凹点雕刻降级;
最低点作为自然合格数。`aclr_psd_shape_eval.py` 成为标准验收工具(PSD 对照图 +
邻带平均偏差 + 凹槽深度 vs 参考自然值 3.10 dB),每个新结果必须出图目检。
平滑续训(HPF,select-metric ref)产出 shape_* 四冠军(2284 −44.74 积分/−45.32 点)。

## 第十阶段:Pareto 混合 + 特征范围重整 + 全量审计(最终)

1. **`aclr_shape_point_blend.py`**:形状锚点与数值锚点在权重空间做分组插值扫描
   (全参数/校正头/仅表/仅 FIR 四种混合方式),在形状守卫(NMSE+积分+形状分+
   自然凹槽)内选点——四模型的形状分与最小点**同时**优于第九阶段
   (点:2284 −45.32→−45.44、998 −43.60→−43.65、786 −40.81→−41.79、796 −41.12→−41.28;
   凹槽超额仅 0.41~1.51 dB)。
2. **`aclr_feature_range_search.py`**:样条表 gmin/gmax 按训练集分位数逐特征重定
   (函数保持式暖启动 + 凸拟合,零 MAC)——796 数值冠军 −41.72→**−41.87**。
3. **`aclr_psd_shape_audit.py`**:对全部历史 best*.pth 统一重评(最小点按
   2048/4096/8192 三种分辨率、平滑中心化 RMSE 形状分、凹槽超额、sha256 去重、
   失败清单),`champions.json` 机选三线冠军,杜绝口径漂移与单 bin 凹点伪装。

最终两套冠军:**best_shape**(shape_point_blend 血统,推荐)与
**best_number**(凸雕刻/特征范围线,数字备选),数字与复现见 `RESULTS.md`;
审计原始产物在 `eval_outputs_direct/aclr_ref_convention/shape_audit_full/`。
