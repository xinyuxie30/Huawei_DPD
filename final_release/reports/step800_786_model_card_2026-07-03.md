# 786 MAC 低秩 EA-TCN 模型卡

## 模型定位

该模型用于展示 800 实乘法器以内的低复杂度 AI-DPD 探索结果。它不是最终达成 -40 dB NMSE 目标的主模型，而是用于说明在极低乘法器预算下，保留 FIR 频域校正并用低秩 pointwise 层换取更深 TCN 记忆建模的效果。

## 结构参数

| 项目 | 参数 |
|---|---|
| checkpoint | `checkpoints/AI-DPD/step800_scratch_h10_l4_base6_rank3_fir41_786.pth` |
| preset | `h10_l4_base6_rank3_fir41_786` |
| 结构 | H10/L4/Input-6/pointwise-rank3/FIR41 |
| 输入特征 | `[I[n], Q[n], I[n+1], Q[n+1], r[n], r[n]^3]` |
| TCN dilation | `[1, 2, 4, 8]` |
| temporal kernel size | 5 |
| attention | 3 通道包络门控 `[r, r^3, r^7]` |
| polynomial bypass | 1/3/5 阶复数旁路 |
| output FIR | 41 taps complex FIR |
| 训练方式 | scratch-only，`teacher-mode none`，无蒸馏 |

乘法器计算：

```text
P=3, C_in=6, H=10, B=4, K=5, rank=3, C_a=3, M=41
C_real = 4P + C_in*H + B*(H*K + 2*H*rank) + 2H + 3*H*C_a + 4M
       = 12 + 60 + 4*(50 + 60) + 20 + 90 + 164
       = 786
```

## 统一评估结果

统一评估脚本：`code/final_evaluate_unified.py`

| 指标 | 数值 |
|---|---:|
| real multipliers | 786 |
| NMSE linear | 2.8431769286770583e-04 |
| NMSE dB | -35.461961 dB |
| target worst ACLR | -48.652289 dBc |
| pred lower ACLR | -46.758996 dBc |
| pred upper ACLR | -48.400353 dBc |
| pred worst ACLR | -46.758996 dBc |
| pred-target ACLR gap | 1.893293 dB |
| margin to -45 dBc threshold | 1.758996 dB |

结论：786 MAC 模型 ACLR 达到 `<= -45 dBc`，但 NMSE 未达到 `<= -40 dB`。相较 796 MAC H10/L3/Input-6/FIR41 基线，786 模型通过低秩 pointwise 增加一层 TCN 记忆深度，统一评估 NMSE 略优，但 ACLR 余量略小。
